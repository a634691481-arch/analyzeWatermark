# 去水印工具 · 重设计需求文档

> 用途：把本文档整段复制给设计师 / 开发 / AI 设计工具，作为重做的唯一输入。
> 版本：v1（基于现有线上站 qsy.mooon.vip）

---

## 1. 产品定位

一个无需登录、无需安装的网页工具：粘贴国内内容平台的分享链接，取回平台云端保存的**无水印原图 / 原视频**，支持单个下载与批量打包。

- 一句话价值：**粘贴链接 → 拿原始文件**，三步完成。
- 不是：图片编辑工具、去水印修图工具、内容搬运工具。
- 目标用户：需要原图原片的普通用户（做素材、做二次创作、备份自己的作品）。

## 2. 核心原则（不可妥协）

1. **诚实**：拿不到真正无水印文件时，必须标注「仅水印版」，不得用带水印文件冒充。
2. **不碰 AI 标识**：AI 生成内容的「AI 生成」水印属法规强制标识，产品不提供任何擦除/遮挡能力。
3. **零门槛**：不登录、不装插件、不填验证码。
4. **快**：解析 1 秒内出结果，下载走服务端代理直连。

## 4. 信息架构

```
/                     首页（通用解析入口）
/{platform}           平台落地页 ×7（doubao/douyin/xiaohongshu/qianwen/bilibili/kuaishou/weibo）
                      未知平台路径直接 404
```

每个平台落地页需要独立的 H1、说明文案、三步引导、FAQ，并互相内链（SEO 需要）。

## 5. 页面模块

### 5.1 首页

| 模块 | 内容 | 优先级 |
| --- | --- | --- |
| Hero | 主标题（一句话说清价值）、副标题、已支持平台展示 | P0 |
| 解析输入区 | 单行输入框（支持整段分享文案）+ 主按钮「解析」 | P0 |
| 输入辅助 | 清空、从剪贴板粘贴 | P1 |
| 结果区 | 平台徽标 + 标题 + 数量统计 + 全选/打包/下载选中 | P0 |
| 媒体卡片 | 缩略图、序号、尺寸/时长、无水印徽标、下载/复制/放大 | P0 |
| 大图预览 | 左右切换、Esc 关闭、下载按钮 | P0 |
| 三步说明 | 「复制文案 → 粘贴解析 → 下载文件」 | P1 |
| 联系作者 | 弹窗表单：联系方式 + 需求 + 自动带上的链接 | P2 |
| 回到顶部 | 移动端长页面 | P2 |

### 5.2 平台落地页

复用首页的解析 + 结果区，另外增加：平台专属 H1 / 说明、平台三步引导、FAQ（3–5 条）、其它平台内链。

### 5.3 全局

- 顶部/底部不设复杂导航，保持单页工具感。
- 不提供登录、历史记录、账号体系。

## 6. 关键交互与状态

### 6.1 解析流程

```
输入 → 点解析 → loading（按钮禁用 + 转圈）
  ├ 成功：结果区出现在输入区下方，默认全选，页面滚动到结果
  └ 失败：toast 提示具体原因，输入内容保留
```

失败文案必须区分：
- 没找到链接
- 不支持该平台
- 链接失效 / 作品已删除
- 页面无可解析内容
- 网络异常

### 6.2 空状态

未解析时展示三步说明，不要留白，也不要放无意义的插画。

### 6.3 下载

- 单个下载：服务端代理，强制附件下载（不内联播放）。
- 批量：勾选后打包 zip，文件数上限 60、总量上限 512MB。
- 打包中需有明确 loading，禁止重复点击。

### 6.4 剪贴板

进入页面 / 首次交互 / 切回标签页时尝试读取剪贴板，仅在输入框为空时填入。
无权限、内容为空、内容不是链接 → 给不同提示，且不打断用户。

### 6.5 清空

输入框内有内容时出现清空图标，点击需二次确认（会同时清掉结果与选中态）。

## 7. 视觉方向

### 7.1 基调

- **固定深色**，不提供明暗切换（原需求的显式约束）。
- 科技感但不炫技：深色底 + 少量绿色微光 + 细边框 + 毛玻璃卡片。
- 主色沿用品牌绿 `#10b981`，辅色青色 `#22d3ee`。

### 7.2 背景

全站统一粒子背景（canvas），粒子随鼠标轻微吸附，靠近边缘淡出。
顶部叠加绿色径向光晕，底部渐隐过渡到纯色底。

### 7.3 组件规范

| 位置 | 处理 |
| --- | --- |
| 主按钮 | 绿色半透明底 + 循环扫光，loading 时图标旋转，禁用降透明度 |
| 媒体卡 | 半透明卡 + 细边框；选中态沿边框跑发光描边 |
| 数字统计 | 进入视口时滚动到目标值 |
| 平台列表 | 横向无限滚动，两侧渐隐遮罩，悬停暂停 |
| 标题 | 白→薄荷渐变文字 |

### 7.4 响应式

| 断点 | 要求 |
| --- | --- |
| < 640 | 输入框与按钮竖排、按钮满宽；结果卡 1 列；步骤卡 1 列；不出现横向滚动 |
| ≥ 640 | 输入框与按钮同行；结果卡 2 列；步骤卡 3 列 |
| ≥ 1024 | 结果卡 3 列；内容容器最大 1152px 居中 |

### 7.5 动效与无障碍

- 所有动画必须尊重 `prefers-reduced-motion`：开启时粒子静止、扫光与跑马灯停止。
- 图标按钮必须有 `aria-label`；弹窗必须有标题。
- 正文字号不小于 12px，移动端点击热区不小于 40px。

## 8. 技术约束

| 项 | 约束 |
| --- | --- |
| 框架 | Nuxt 4（SSR）+ Vue 3 + Nuxt UI 4 + Tailwind 4 |
| 部署 | Vercel，函数区域**必须 hkg1（香港）**，否则国内平台抓不到数据 |
| 包管理 | pnpm |
| 不引入 | 账号体系、数据库、第三方抓取 SDK |
| SEO | 每页独立 title/description/canonical，平台页需 FAQ 结构化数据 |
| PWA | 可安装 + 静态资源离线可用，不缓存解析出的媒体 |

## 9. Non-goals（明确不做）

- 不做图片去水印/修补（只取平台已有的原始文件）。
- 不做 AI 生成标识擦除。
- 不做登录、收藏、历史记录、云同步。
- 不做明暗主题切换。
- 不做付费、会员、广告位。
- 不保证付费/限定/私密内容的解析。

## 10. 验收标准

1. 粘贴任意支持平台的分享文案（含中文、emoji、多余文字），能正确提取链接并解析。
2. 解析成功到结果渲染 ≤ 1.5s（不含首次冷启动）。
3. 图片卡片首屏不加载原图（用缩略图），单张流量 ≤ 300KB。
4. 移动端 375px 宽度下无横向滚动、按钮不折行、结果网格单列。
5. 键盘可完成：输入 → 回车解析 → Tab 到卡片 → 空格勾选。
6. 关闭动画（系统减少动效）后，页面功能完全可用。
7. Lighthouse 移动端：性能 ≥ 85、可访问性 ≥ 90。
